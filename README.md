# Karan Panchal — Portfolio

Personal portfolio website for Karan Panchal, Computer Engineering Student & Developer.

## 🗂 File Structure

```
portfolio/
│
├── index.html                  # Main HTML file
├── style.css                   # All styles (CSS variables, layout, animations)
├── script.js                   # All interactions & animations
│
├── assets/
│   ├── images/
│   │   ├── profile-1.jpg       # Primary profile photo (place here)
│   │   └── profile-2.jpg       # Secondary profile photo (optional)
│   │
│   ├── certificates/
│   │   ├── epd-achievement.jpg
│   │   ├── epd-participation.jpg
│   │   ├── dsa-java.jpg
│   │   ├── postgresql.jpg
│   │   ├── ai.jpg
│   │   ├── cybersecurity.jpg
│   │   └── adobe-cloud.jpg
│   │
│   └── resume/
│       └── Karan_Panchal_Resume.pdf
│
└── README.md
```

## 🚀 Getting Started

1. Place your profile photo at `assets/images/profile-1.jpg`
2. Place your certificates in `assets/certificates/` using the filenames above
3. Place your resume at `assets/resume/Karan_Panchal_Resume.pdf`
4. Open `index.html` in your browser — no build step required

## ✅ Features

- Full-screen hero with animated particle canvas
- Rotating keyword line
- Animated skill proficiency bars
- Scroll reveal animations
- Animated CGPA counters
- Certificate modal/lightbox viewer
- Mobile-responsive navigation with hamburger menu
- Smooth scrolling
- Resume download button
- All social links (GitHub, LinkedIn, Instagram, X)
- Achievement highlight banner
- Featured project card + compact project list
- Accessible: semantic HTML, aria-labels, focus states, reduced-motion support
- SEO meta tags

This is a static website. It can be deployed to:

- **Netlify** — drag and drop the `portfolio/` folder
- **Vercel** — import and deploy as static
- Any static file host
